# 智能网关 XG-200 部署手册

## 型号与规格

XG-200 是标准版网关，支持 32 台子设备，以太网供电 PoE。
XG-200Pro 是增强版，支持 128 台子设备，内置 4G 备份链路。
型号铭牌位于设备底部标签，格式为 XG-200/REV.C。

## 网络配置

网关默认 IP 为 192.168.8.100，首次登录后台 http://192.168.8.100 使用 admin 账号。
DHCP 冲突时请将网关设为静态地址段 192.168.9.x 并关闭上级路由的 DHCP 池。
固件版本 V2.3.7 起支持 MQTT over TLS，证书在"安全设置-证书管理"上传。

## 指示灯含义

绿色常亮：正常运行且已连接云端。
绿色呼吸：局域网正常但云端断连，检查外网 DNS 与 8883 端口。
红色快闪：OTA 升级中，切勿断电。
红色常亮：电机堵转或存储满，长按 RESET 5 秒进入恢复模式。

## 故障排查：设备频繁掉线

步骤一：确认子设备信号强度 RSSI 优于 -75dBm。
步骤二：在"诊断-信道分析"中查看 2.4G 信道拥塞度，拥塞度高于 70% 时切换信道 1/6/11。
步骤三：若仅个别时段掉线，检查是否与管理系统的定时重启任务冲突，默认任务时间为凌晨 3:17。
