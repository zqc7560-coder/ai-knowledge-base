## M7.2 AI 用量成本落库 ✅（2026-11-02）
- 实现：V4 迁移给 `ai_usage_daily` 加 prompt/completion/emb/rerank/vision 列；`AiClientFactory` 解析 OpenAI 兼容 `usage`（chat/embed/rerank；流式在带 usage 的末 chunk 记录，拿不到不虚构——口径如实）；`visionOcr` 返回 `VisionResult(text,totalTokens)`。归因用 `UsageContext`(ThreadLocal)：问答在 ssePool 线程绑 userId（finally 必清防串号），文档管道绑 kbId→`UsageRecorder.ownerOf` 查 `knowledge_bases.owner_id`（带 5 分钟缓存，重启安全）；写库同 (user,date) 行用 stripe 锁串行，record 全程吞错只 warn（统计不影响业务）。

- 实测：上传(emb 839 tokens)+问答+reindex 后，`/admin/usage-month` 返回 tokens=41,838、估算成本 ¥55.13（含历史 M6 时段回填后口径），冒烟两项 PASS。
