## 检索调试权限改 ADMIN 专属（2026-11-03 晚，11cc8ce）
- 用户质询：管理员工具为何普通用户可见可用。第一轮我按后端原设计（M8"ASK 即可用"）做 myRank 入口显隐——**用户实测仍可见**：环境存在 PUBLIC 库，所有登录用户天然 ASK=2，显隐条件形同虚设；且"点进去才被后端拒"仍是差体验。
- 第二轮遵从用户意图收紧为 **ADMIN 专属**，三层一致：
  - 后端：`RetrieveDebugController` 类级 `@SaCheckRole("ADMIN")`——普通用户（含库 owner 本人、PUBLIC 库提问者）一律 2002；ADMIN 可跨 owner 调试任意库（含 PRIVATE），这是运维排障视角，`loadExisting` 只验库存在、行为打日志留痕。
  - 路由守卫：`/debug`、`/audit` 非管理员直接弹回首页（修第一轮"只 v-if 不防 URL 直达"的残留；守卫里 `loadMe` 补齐刷新后未加载的角色）。
  - 入口：KbListView 顶栏与设置对话框按钮 `v-if=isAdmin`；DebugView 下拉取管理员可见全量（myRank 过滤撤销）。
- 验证：后端专项 5/5（owner 本人 2002/PUBLIC-ASK 用户 2002/ADMIN 跨 owner 放行/参数守卫/列表仍带 myRank）+ Playwright 三断言（普通用户按钮数 0、直达 URL 弹回、管理员按钮 1 且面板 6 库可跑）+ 截图视觉复核 + build 绿 + 冒烟 73/73。
- 保留说明：`GET /kb` 的 myRank 瞬态字段保留（列表通用能力，第一轮的 8 条折算单测仍有效）；`GET /debug` 面板不生成答案不落库不耗配额，收紧后普通用户的"为什么搜不到"诉求由管理员代查——与用户要求一致。
