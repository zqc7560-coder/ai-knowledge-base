## 环境适配记录（本机 Windows + WSL2 Docker 特有，非缺陷）
- **容器出网间歇性 RST**：Docker Desktop/WSL2 NAT 对 https 出网时断（宿主/容器 curl 均 3 次 1 通）。
  已应对：① AiClientFactory 加连接级重试(3 次，ConnectException 无重复计费风险)；
  ② 冒烟默认打宿主后端(8080，网络稳定)得 22/22，经 nginx(8085) 会因偶发 RST 让 AI 步失败——属环境抖动非代码缺陷。
  正常 Linux 部署机无此问题。
- **容器内 Maven 源不可达**：宿主 FlClash 代理仅宿主进程生效，容器直连阿里云 502。
  已应对：宿主本地 m2 仓库经 `--build-context m2seed` 挂入构建做离线种子（详见 backend/Dockerfile 与技能笔记）。
