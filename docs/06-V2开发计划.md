## M8–M12 关键设计决策（开工前定，实施时细化）

- **Parent-Child**：切片时父子双写（child=现粒度可检索，parent=同文档更大窗口），检索命中 child、送 LLM 前替换为 parent 去重合并；kb 设置 `parentChild.enabled`，默认关，评估集对比开/关。
- **本地 rerank**：bge-reranker ONNX 需下载 ~1GB 模型且本机磁盘/网络受限风险高 → **策略**：保持 DashScope gte-rerank-v2 为主，新增 rerank 结果 Redis 缓存（同 query+同候选集命中免 API、降 429）——以"缓存"替代"本地模型"达成成本目标，若模型下载实际可达再补本地实现。
- **评估扩容**：qwen-plus 从全语料自动生成 QA（限定"答案必须是文中可定位的片段"），程序去重+长度过滤，人工抽检 20%，目标 150–200 题、含跨库混淆与对抗题；`eval_rag.py` 支持 --kb 参数与消融矩阵。
- **图片进 OCR**：DocxParser/PdfParser 抽取内嵌图（大小>50KB、每文档≤20 张护栏）→ 复用 OcrService → 图注文本作为独立 section（标记来源"图内文字"）。
- **URL 入库**：SSRF 三防线——仅 http/https、DNS 解析后拒绝私有/环回/链路本地段、跟随重定向≤3 且每跳复检；正文用正则提取（标题+段落），上限 500KB。
- **开放 API**：每用户最多 10 个 key（`sha256` 存库、明文仅创建时显示一次），`/api/open/ask` Bearer key 鉴权 → 限定 key 绑定的库子集；独立限流计数。
- **文档级权限**：documents 加 `restricted` 位 + `doc_permissions` 表（READ/ASK），ASK 时向量召回后按用户可见 doc 集过滤；owner/admin 不受限。默认关闭（兼容现有行为）。
- **审计日志**：`audit_logs`（用户、IP、动作、目标、时间），覆盖删库/改权限/成员变更/分享创建/禁用账号/角色升降；管理页列表+分页。
- **密码找回**：SMTP 走环境变量（MAIL_* 未配置则按钮置灰提示）；重置 token 存 Redis 15 分钟一次性。
- **Playwright E2E**：主链路"注册→建库→传 md→等 READY→提问→引用抽屉→点踩→导出"；CI 里跑在 compose profile=app 上（若 Actions 环境网络不稳，记录后降级为本地跑）。
